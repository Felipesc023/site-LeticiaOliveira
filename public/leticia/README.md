# Retratos

Geradas por `node scripts/build-assets.mjs "<pasta de origem>"` a partir das fotos
originais (HEIC do iPhone convertidas automaticamente).

| Arquivo       | Origem              | Uso                                      |
|---------------|---------------------|------------------------------------------|
| `home.jpg`    | IMG_2467 (vestido marrom, braços cruzados) | Home — paleta da marca, autoridade |
| `sobre.jpg`   | IMG_3749 (perfil 3/4, expressão séria)     | Sobre — tom editorial              |
| `contato.jpg` | IMG_3741 (frente, sorriso, fundo neutro)   | Contato — abertura, acolhimento    |

Para trocar: substitua os arquivos de origem e rode o script de novo, ou
coloque um `.jpg` novo aqui com o mesmo nome. Sem o arquivo, o componente
`Portrait` mostra um placeholder com o nome esperado.
